# Images

Photos and logos used across the site, copied from the current website.

- `home-hero.png` — homepage hero photo (Stacey and Cesc), cut out with a transparent background so the navy shows behind
- `Stacey_Cesc.png` — the original of that photo
- `hero.webp` — used as the preview picture when the homepage is shared on social media
- `our-story.webp`, `network.webp`, `blog.webp`, `contact.webp` — page header photos
- `services/` — service header photos; `services/detail/` — the second photo on each service page
- `members/stacey-hope.webp` — Stacey's photo on Our Story
- `network/` — partner logos
- `blog/` — blog post photos (`blog-1` is the oldest post)
- `friendship.webp`, `wwtw-logo-c.webp` — used on Our Story

To swap a photo, replace the file and keep the same name.
